# QueueLess

**Know Before You Go.**

## About the Project

QueueLess is a service information website designed to help people find service centres, check opening hours, learn about available services, and plan their visits before leaving home.

## Problem Statement

People often visit service centres without knowing their opening hours, the services offered, or the requirements they need to meet before arriving. This can lead to wasted time, unnecessary trips, and inconvenience.

## Project Objectives

- Help users discover different service centres.
- Provide information about available services and opening hours.
- Organize services into easy-to-browse categories.
- Help users prepare for their visits.
- Provide safety tips for visiting service centres.
- Make service information easy to access through a simple, responsive website.

## Features

### 1. Homepage

Introduces QueueLess, explains its purpose, and helps users navigate the website.

### 2. Services Page

Displays the available service categories and provides links to relevant service information.

### 3. Centres Page

Lists service centres and provides basic information to help users find suitable centres.

### 4. Health Centre Details Page

Provides information about Naivasha Health Centre, including its services, opening hours, and visit requirements.

### 5. Service Details Page

Provides information about banking, government, education, digital, and repair services.

### 6. About Us Page

Explains the purpose, mission, and problem-solving approach of QueueLess.

### 7. Safety Page

Provides useful safety tips to help users verify information, protect their documents, and prepare for their visits.

### 8. Plan Your Visit Page

Guides users through the steps to prepare for a visit, including checking opening hours, gathering documents, confirming requirements, and planning their journey.

## How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Navigate through the website using the available links.
